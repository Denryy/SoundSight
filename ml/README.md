# ml/ — захват жестов и путь к генеративному аватару

Каталог инструментов для пополнения жестового лексикона собственного
3D-аватара (`avatar/native_lexicon.json`) и заметок о следующем шаге —
генеративной модели «текст → движение».

## extract_pose_clip.py — жест из видео за минуту

Скрипт превращает видеозапись жеста в клип формата проекта: MediaPipe Holistic
извлекает 3D-ориентиры тела и кистей, затем они анатомически ретаргетятся в
суставные углы контракта поз (`frontend-react/src/avatar3d/poseTypes.ts`).

```bash
pip install -r ml/requirements.txt

# проверить, что математика ретаргета цела (MediaPipe не нужен)
python ml/extract_pose_clip.py --self-test

# жест «спасибо» из видео сразу в лексикон бэкенда
python ml/extract_pose_clip.py video/spasibo.mp4 \
    --gloss thanks --ru "спасибо" --aliases "thank,thank you" \
    --merge avatar/native_lexicon.json --start 0.4 --end 2.1
```

После записи откройте **Аватар-лаб → Глоссы** и проиграйте жест: подъём плеча,
локоть и сгибы пальцев из монокулярного видео получаются устойчиво, а вот
вращение предплечья (`tw`), осевое вращение плеча (`sh[2]`) и кисть (`wr`)
оцениваются приблизительно — их доводят слайдерами во вкладке «Поза» и
правят цифры в JSON.

### Как снимать, чтобы получалось хорошо

— строго фронтально, по пояс, руки не выходят из кадра;
— ровный свет, однотонный фон, без перчаток; 720p и выше;
— один жест на ролик, по краям по полсекунды покоя (обрежьте `--start/--end`);
— если запись с «зеркальной» фронтальной камеры — добавьте `--mirror`,
  иначе правая и левая руки поменяются местами.

### Полезные ключи

`--fps 15` — частота сэмплирования; `--min-delta 4` — порог прореживания
ключевых кадров (меньше = плавнее и тяжелее JSON); `--hands r|l|both`;
`--hold 220` — удержание финальной позы, мс.

## Дальше: генеративная модель (роадмап)

Сейчас аватар работает по словарю + дактилю. Полноценная генерация
«любой текст → связное жестовое предложение» — это отдельная ML-задача,
эталон которой задаёт SignAvatars (ECCV 2024): большой корпус движений в
параметрах тела SMPL-X и связка VQ-VAE + авторегрессионный трансформер
(текст/глоссы → токены движения). Реалистичный план для SoundSight:

1. **Данные.** Региональные корпуса: FluentSigners-50 (казахстанский ЖЯ,
   открытый, krslproject.github.io/fluentsigners-50/) и Slovo (РЖЯ, 20k видео).
   Прогнать видео через MediaPipe/SMPLer-X → последовательности поз.
2. **Словарь движения.** Обучить VQ-VAE на последовательностях углов нашего
   контракта (или SMPL-X с ретаргетом — `extract_pose_clip.py` уже содержит
   нужную векторную математику «скелет → наши каналы»).
3. **Генератор.** Трансформер «глоссы → токены движения» в духе T2M-GPT;
   глоссировка текста — отдельная seq2seq-модель или LLM-подсказка.
4. **Интеграция.** Бэкенд вместо словарного роутинга вызывает модель и кладёт
   результат в тот же `payload.avatar_pose` — фронтенд менять не придётся.

Шаги 1–3 требуют GPU и недель работы; текущая словарная схема — честная
ступень к ним с тем же форматом данных.
