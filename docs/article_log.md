# SoundSight — журнал работ (для статьи)

Рабочий лог технических улучшений **SoundSight** — агента доступности лекций для
слабослышащих (живые субтитры + жестовый 3D-аватар + авто-резюме сессии).
Пополняется по ходу работы. Числа — из офлайн-тестов и реального запуска.

---

## 1. Живое зеркало: адаптивное сглаживание 1€-фильтром

**Проблема.** Поток поз с веб-камеры (MediaPipe Tasks → ретаргет) дрожит.
Постоянный коэффициент сглаживания — это вечный компромисс: сильное сглаживание
убирает дрожь, но добавляет лаг; слабое — наоборот. Ни одно значение не хорошо
сразу и в покое, и в движении.

**Решение.** Внедрён **1€ (One-Euro) фильтр** (Casiez, Roussel, Vogel, CHI 2012):
частота среза адаптивна — в покое низкая (давит дрожь), на скорости растёт
(давит лаг). Фильтруем поканально углы позы (единые единицы — градусы, нет
обёртки ±180). Файл: `frontend-react/src/avatar3d/oneEuro.ts`, включён в
live-путь плеера (`avatar3d/player.ts`).

**Результат** (офлайн-тест `node ml/one_euro_test.mjs`, против прежнего
постоянного лерпа 0.35):

| Метрика | Старый лерп 0.35 | **1€-фильтр** |
|---|---|---|
| Дрожь в покое (вход ±3°) | ±1.63° | **±1.35°** |
| Отклик на шаг 0→90° (через 3 кадра) | 73.9° | **89.1°** |
| Лаг на непрерывном движении | 7.4° | **3.5°** |

Выигрыш по **обеим** осям одновременно — то, чего постоянным коэффициентом не
добиться. Параметры (`LIVE_MINCUTOFF=1.0`, `LIVE_BETA=0.02`) вынесены константами
для тонкой настройки в «Аватар-лаб».

## 2. Дактиль на скиновой 3D-модели: разведение пальцев

**Проблема.** На скиновой модели (Mixamo glTF) пальцы при дактиле не
растопыривались — ретаргет переносил только сгиб (curl), а разведение
(abduction) терялось. Из-за этого кисть выглядела «когтистой», а буквы,
различающиеся только разведением (В/И, Р-крест, ASL U/V), сливались в одну форму.

**Решение.** В ретаргет пальцев (`avatar3d/skinnedHumanoid.ts`) добавлен перенос
разведения: проксимальная фаланга доворачивается вокруг нормали ладони на угол
spread-сустава драйвера. Знак — один на кисть, определяется геометрически;
направление каждого пальца уже закодировано в данных, поэтому общий доворот
разводит пальцы веером, а отрицательный spread (Р/ASL R) — скрещивает.
Проверка: `node ml/spread_test.mjs` (веер на +spread, крест на −spread).

## 3. Аудит кодовой базы и устойчивость

Сплошной аудит выявил и закрыл реальные дефекты:

- **Гонка одновременных WebSocket-подключений** на singleton-конвейере → guard
  одного активного субтитр-стрима.
- **Ресэмплинг блокировал event-loop** → вынесен в executor (живой звук не
  стопорится).
- **ASR залипал при смене языка** (ошибка загрузки оставляла движок без модели) →
  откат к рабочему режиму + чистая ошибка на API.
- **Молчаливое глотание ошибок аватара** → логирование с трейсом.
- **Валидация в датасет-роутах** консолидирована, защита от обхода путей,
  без пустых папок при отказе.
- Фильтр-списки шума сведены в единый источник (`core/lexicon.py`); убраны дубли,
  мёртвый код и устаревшие ссылки.
- Фронтенд: устранены гонка двойного старта сессии, утечка/воскрешение аватара
  после размонтирования, ненадёжное восстановление WASM-загрузчика, дубли утилит.
- Унифицировано продуктовое именование **SoundSight** по всему коду, докам и UI.

## 4. Подтверждение работоспособности (реальный запуск)

Бэкенд поднят локально (`python main.py`, отдаёт собранный React SPA из
`frontend-react/dist`):

- ASR `large-v3-turbo` загружена на **GPU (CUDA fp16, 1.51 ГБ VRAM)**, прогрев
  1.87 c, темп interim-субтитров 0.6 c.
- `http://0.0.0.0:8000` — `/health` 200; React SPA отдаётся; API
  (`/session/mode`, `/avatar/dataset`, `/avatar/native/lexicon`) отвечает.
- Ассеты живого зеркала отдаются в проде: модель MediaPipe
  `pose_landmarker_full.task` → HTTP 200, 9.4 МБ.

## 5. Честные ограничения

- Монокулярная оценка скрутки предплечья/поворота кисти (`tw/rot/wr`) остаётся
  приблизительной; сгибы и формы кистей — точные. Лево/право калибруется тумблером.
- Визуальная корректность зеркала и финальный «фил» сглаживания требуют браузера с
  камерой — математика и проводка подтверждены офлайн, движение перед камерой — нет.

## 6. Как воспроизвести проверки

```bash
uv run pytest                       # юнит/интеграция бэкенда
node ml/one_euro_test.mjs           # сглаживание зеркала
node ml/spread_test.mjs             # разведение пальцев
node ml/retarget_pose_test.mjs      # математика ретаргета позы
node ml/retarget_test.mjs           # кватернионы скиновой модели

# Сборка фронта + запуск
cd frontend-react && npm run build
python main.py                      # → http://localhost:8000
```
